# Tài liệu WYCK

Simulator giấy Wyckoff trên nến Binance USDT-M. Một chiến lược, làm sâu. Không phải bot thật.

Kế hoạch gốc là bản hoàn thiện. Bản lộ trình game chỉ còn giá trị ở những chỗ không đụng độ nó.

| Tài liệu | Vai trò |
|---|---|
| [ke-hoach-hoan-thien.md](./ke-hoach-hoan-thien.md) | Kế hoạch 0.1. Đích, nguyên tắc, S0–S6, cổng, rủi ro. Thắng khi mâu thuẫn |
| [s0-dac-ta.md](./s0-dac-ta.md) | Đặc tả golden master, export Pine, diff. Năm câu hỏi mở mới là đề xuất |
| [ke-hoach-phat-trien-wyck.md](./ke-hoach-phat-trien-wyck.md) | Hiện trạng bàn đang chạy: vốn, warmup, luật Eye, dữ liệu. Không còn là lộ trình |

Thứ tự làm: S0 rồi S1 rồi S2. Chưa viết code S0 khi năm câu ở mục 9 của kế hoạch gốc chưa được duyệt.
